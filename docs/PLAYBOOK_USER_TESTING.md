# Playbook: real user testing

Observe (do not lead):

1. Where users hesitate on Interview setup (field vs pack vs mode)
2. Misunderstandings of Leave vs End
3. Abandon points (silence, voice download, first question)
4. Which Analytics sections they scroll (coach vs charts vs transcript)
5. Which Home recommendations they ignore

Capture notes offline; optionally ask users to Export diagnostics (anonymous) if they consent.
